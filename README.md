# Save Room

Личный сайт Игоря: проекты, эксперименты и небольшие истории о том, что получилось сделать.
SvelteKit со статической сборкой, TypeScript, FSD, JSON-публикации и [Svelte ASCII UI](https://github.com/IgorLo/svelte-ascii-ui) версии 0.2.0.

## Разработка

Node.js 22.19.0 (см. `.nvmrc`), npm. После клонирования:

```sh
npm ci
npm run dev
```

Адрес напечатает Vite. Для просмотра production-сборки: `npm run build`, затем `npm run preview`.
Изображения и шрифты поставляются локально. Исходные папки других проектов для работы сайта не нужны.

## Проверки

```sh
npm run verify
npx playwright install chromium --only-shell
npm run test:e2e
```

`verify` проверяет форматирование, ESLint без предупреждений, архитектуру Steiger, TypeScript/Svelte, JSON и изображения, unit-тесты, затем собирает сайт.
Браузерные тесты запускают локальный сервер готовой папки `build` (поэтому сначала нужен `npm run verify` или `npm run build`). Проверяют 1440px и 360px, прямые адреса всех пяти статей, переходы, отсутствие недоступных ссылок, метаданные, настоящую статическую 404, увеличение текста и клавиатурное управление просмотром изображений.
При включённом системном прокси тесты исключают localhost из проксирования.

## Новая публикация

1. Добавить картинки в `static/images/projects/<slug>/`. Поддерживаются WebP, PNG и JPEG. Имена файлов и папок — латинские буквы в нижнем регистре, цифры и дефисы.
2. Добавить JSON в `content/projects/`. Имя файла служит только для удобства; сортировка определяется полями записи.
3. Запустить `npm run format`, `npm run verify`; проверить страницу локально.

Минимальная запись:

```json
{
	"id": "my-project",
	"slug": "my-project",
	"title": "Мой проект",
	"summary": "Короткое описание для главной.",
	"createdAt": "2026-11-06",
	"order": 1,
	"pinned": false,
	"cover": {
		"src": "/images/projects/my-project/cover.webp",
		"alt": "Что изображено на обложке"
	},
	"links": [],
	"body": [{ "type": "paragraph", "text": "Моя история." }]
}
```

Блоки `body` идут в порядке чтения. В текущих статьях текст расположен перед скриншотами; при необходимости изображение можно вставить и между абзацами:

- `paragraph`: `text` — абзац обычного текста.
- `heading`: `text` — подзаголовок второго уровня.
- `list`: `items` — массив непустых строк.
- `image`: `src`, `alt`, необязательная `caption` — изображение с доступным увеличением. Миниатюра ограничена высотой 600 px без обрезки; в окне просмотра она может быть крупнее. Поля `width` и `height` задают размер исходного изображения в пикселях и резервируют место до загрузки; у текущих иллюстраций они заполнены.

В `links` можно добавить по одной ссылке каждого вида: `{"kind":"project","label":"Открыть проект","href":"https://example.com"}` и `{"kind":"source","label":"Исходники","href":"https://github.com/owner/repo"}`. Нет доступного адреса — оставить пустой массив; пустые кнопки не появляются. Приватные репозитории не делать публичными ради сайта и не обозначать как доступные исходники.

`createdAt` — необязательная дата первого коммита проекта в формате `YYYY-MM-DD`; если она неизвестна, поле не указывать. Записи без даты идут после датированных. `order` задаёт порядок «По прикольности» на главной: HASCII, Svelte ASCII UI, «Все псы попадают в рай», ВДА-бот, Dog Day Afternoon. «По дате» показывает новые проекты раньше старых. `pinned: true` закрепляет датированную запись в начале обеих сортировок. При равенстве используются `order` и `slug` для стабильности. ID и slug уникальны; изменение slug меняет адрес статьи.

Текущие даты сверены с первыми коммитами и показаны по московскому времени: «Все псы попадают в рай» — [27.09.2026](https://github.com/GameDevCompanyName/DogsGoToHeaven/commit/440ddd80dde93ab31974dfb2e8ab78db3c3ce14c), HASCII — [09.11.2026](https://github.com/IgorLo/hascii/commit/ad0984c9e63efb5dfc529d7c4d22b0f97ac01b06), Svelte ASCII UI — [08.11.2026](https://github.com/IgorLo/svelte-ascii-ui/commit/51314d636c56ef051397ac2270292a528aeacafc), ВДА-бот — 24.10.2026 (приватный репозиторий). Первый коммит «Всех псов» сделан 26.09 в 22:59 UTC, что соответствует 27.09 в Москве. Для Dog Day Afternoon дата пока не указана.

Строки содержат обычный текст, не HTML. Проверка сборки отвергает неизвестные поля/блоки, неверные даты, дубликаты, неподходящие URL и отсутствующие изображения с указанием проблемной записи.

## Где что менять

Интерфейс использует опубликованный пакет `svelte-ascii-ui@0.3.0`: `Theme` задаёт палитру, `Link` оформляет навигацию и кнопки-ссылки, `Separator` — разделители, `Panel` — карточки проектов, `Article` — текст публикаций, `Figure` — скриншоты и их просмотр, `EmptyState` — экран ошибки в SvelteKit. Структура страниц, чередование карточек, аватар и обложки остаются компонентами Save Room. При изменениях UI читайте руководство установленного пакета, на которое указывает `AGENTS.md`.

- `src/shared/config/profile.ts` — приветствие, фотография и пять личных ссылок. Заголовок и текст также используются для метаданных превью главной страницы.
- `src/shared/config/theme.ts` — семь цветов темы Svelte ASCII UI и оттенок фонового ASCII-арта; `src/shared/ui/RoomBackground.svelte` — узор и скорость движения; `src/shared/styles/global.css` — внешний макет и типографика. Кнопка в шапке останавливает анимацию, а системное предпочтение уменьшения движения учитывается библиотекой.
- `src/entities/project` — модель, серверный загрузчик и компоненты публикации.
- `src/widgets` — вступление и лента.
- `src/routes` — тонкая интеграция с маршрутизацией SvelteKit.

Компоненты не читают файлы. `getProjects()` и `getProject(slug)` возвращают проверенные объекты; будущий API может заменить файловый источник с сохранением контракта. Клиентский публичный API не экспортирует серверный загрузчик.

Steiger проверяет FSD. Исключено только эвристическое `fsd/insignificant-slice`: оно не видит потребителей в `src/routes`, потому что маршруты SvelteKit не являются FSD-слоем. Остальные правила действуют. Общие компоненты не зависят от сущностей или виджетов.

## Vercel

Импортировать репозиторий `IgorLo/SaveRoom`, выбрать SvelteKit, Node 22.x и `main` как production-ветку. `vercel.json` задаёт `npm ci` и `npm run build`; adapter-static автоматически создаёт Vercel build output. Проверки форматирования, линтеров, типов, контента и тестов выполняет GitHub Actions. После сборки `scripts/configure-hosting.mjs` добавляет маршрут неизвестных адресов на сгенерированный `/404.html` со статусом 404. Не включать SPA-rewrite всех путей на главную.

Для стабильных ссылок Open Graph можно задать `PUBLIC_SITE_URL` с итоговым HTTPS-адресом без завершающего слеша. Без неё статическая сборка использует текущий публичный адрес `https://save-room-psi.vercel.app`; preview на Vercel использует свой `VERCEL_URL`. Локальный dev-сервер использует собственный origin.
Превью главной страницы берёт заголовок и описание из `profile.ts`, фотографию — из `profile.avatar`; отдельная картинка для карточки ссылки не создаётся. Это статическая сборка: после изменения профиля нужен новый деплой, а Telegram и другие сервисы могут хранить старую карточку в своём кеше. Они также сами выбирают форму карточки и длину видимого текста.

GitHub Actions проверяет изменения и запускает браузерные тесты. Перед слиянием в `main` должен пройти job `verify`; в настройках GitHub рекомендуется сделать его обязательным. Vercel собирает сайт для публикации. Подключение аккаунта Vercel и защита ветки — отдельные настройки, наличие файлов конфигурации само по себе их не включает.
